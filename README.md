# KAUST AI Program -- Stage 2

## Introduction to Artificial Intelligence

### Machine Learning & Introduction to Deep Learning

------------------------------------------------------------------------

## 📌 Overview

This repository contains all materials, assignments, projects, and
resources for **KAUST AI Program -- Stage 2**, focused on foundational
concepts in:

-   Artificial Intelligence
-   Machine Learning
-   Introduction to Deep Learning

This stage builds the theoretical understanding and practical skills
required to design, train, and evaluate machine learning and deep
learning models.

------------------------------------------------------------------------

## 🎯 Learning Objectives

By the end of Stage 2, students will be able to:

-   Understand core AI and ML concepts
-   Implement supervised and unsupervised learning algorithms
-   Perform data preprocessing and feature engineering
-   Evaluate model performance using appropriate metrics
-   Understand neural networks and deep learning fundamentals
-   Build simple deep learning models using modern frameworks

------------------------------------------------------------------------

## 📚 Topics Covered

### 1️⃣ Introduction to Artificial Intelligence

-   What is AI?
-   Types of AI systems
-   AI vs ML vs Deep Learning
-   Applications of AI
-   Ethics in AI

### 2️⃣ Machine Learning Fundamentals

-   Supervised vs Unsupervised Learning
-   Regression
-   Classification
-   Clustering
-   Model evaluation metrics
-   Overfitting & Underfitting
-   Cross-validation
-   Bias-Variance tradeoff

### 3️⃣ Data Preprocessing

-   Data cleaning
-   Handling missing values
-   Encoding categorical variables
-   Feature scaling
-   Train/Test split

### 4️⃣ Core ML Algorithms

-   Linear Regression
-   Logistic Regression
-   k-Nearest Neighbors (kNN)
-   Decision Trees
-   Random Forest
-   Support Vector Machines (SVM)
-   K-Means Clustering

### 5️⃣ Introduction to Deep Learning

-   Biological vs Artificial Neurons
-   Perceptron
-   Neural Networks basics
-   Activation functions
-   Forward & Backpropagation
-   Loss functions
-   Gradient Descent
-   Introduction to CNNs

------------------------------------------------------------------------

## 🚀 Final Project

Students will apply machine learning and introductory deep learning
techniques to solve a real-world problem, including:

-   Problem definition
-   Data preprocessing
-   Model selection
-   Training & evaluation
-   Result analysis
-   Final presentation/report
